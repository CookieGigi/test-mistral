The Canvas — how it works

The textarea at the center is the only thing the agent can see and touch. It works in steps: read the canvas → emit plain notes and directives → the directives physically edit the canvas → repeat. Every step is snapshotted, token counts are recomputed live, and the loop stops on [[done]], step limit, or Stop.

Directives the agent may emit

[[write: Name]] … [[end]]     rewrite section «Name» (create it if needed)
[[append: Name]] … [[end]]    add lines at the end of section «Name»
[[note: one line]]            quick note into section «Notes»
[[delete: Name]]              remove a section entirely
[[find: pattern]]             grep the canvas; results land in «Findings»
[[pin: Name]] / [[unpin: Name]]   protect a section from auto-trim
[[ask: question]]             pause and wait for a human answer
[[done]]                      mission complete

Sections

Any line starting with ## starts a named section. The outline (left) lists them with token weight; pinned sections survive auto-trim.
