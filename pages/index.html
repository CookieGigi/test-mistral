WebLLM Playground

Two experiments built on WebLLM: models run fully in your browser via WebGPU — no server, no API keys.

the canvas

An agent that lives in your textarea

The whole textarea is the agent's memory and workspace. It reads it, rewrites it through directives ([[write]], [[find]], [[ask]]…), snapshots every step, pauses mid-mission to ask you questions, and auto-trims its memory to fit the context window.

agentic loop

Minimal agentic loop

The seed experiment: one editable text area is the entire context. Each run appends the model's output back into the same box, feeding on itself — with live tokenizer budget capped to the model's context window.

Runs best in Chrome / Edge 113+ (WebGPU). First model load downloads the weights (~300 MB for the default 0.5B). Sources: CookieGigi/test-mistral
